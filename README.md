## 安装说明

1. 下载 Automeo-Setup-0.16.16.exe
2. 双击运行安装程序
3. 选择安装目录（默认即可）
4. 点击安装，等待完成
5. 安装完成后自动启动

## 自动更新

应用内置自动更新功能，检测到新版本后会在后台自动下载，重启时自动安装。

## 系统要求

- Windows 10/11 (64位)
- 至少 2GB 可用磁盘空间
- 网络连接（首次启动需初始化数据库）
