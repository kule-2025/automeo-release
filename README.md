# Automeo 全自动经营管理系统

> 从商机发现到财务结算的全流程自动化经营管理平台

## 📦 下载安装

### 最新版本：v0.14.0

| 平台 | 下载 | 大小 |
|------|------|------|
| Windows x64 | [Automeo-Setup-0.14.0.exe](./Automeo-Setup-0.14.0.exe) | 89.98 MB |

### 系统要求

- **操作系统**：Windows 10 / Windows 11 (64位)
- **内存**：最低 4GB，推荐 8GB+
- **磁盘空间**：最低 500MB 可用空间
- **网络**：需要互联网连接

### 安装说明

1. 下载 `Automeo-Setup-0.14.0.exe`
2. 双击运行安装程序
3. 选择安装目录（支持自定义安装路径）
4. 选择是否创建桌面快捷方式和开始菜单快捷方式
5. 点击安装，等待完成
6. 安装完成后可选择立即启动 Automeo

### 自动更新

Automeo 支持应用内自动检测更新和无感更新：
- 启动时自动检查新版本
- 发现更新时弹出提示，显示更新内容
- 支持后台下载更新包，显示下载进度
- 下载完成后提示重启应用以完成更新
